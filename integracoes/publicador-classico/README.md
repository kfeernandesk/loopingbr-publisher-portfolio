# Publicador clássico — registro de evolução

Esta pasta preserva os scripts Python e workflows de uma **exportação anterior** do LoopingBR Publisher, recuperada do pacote de cópia para testes. Mostra uma etapa real da evolução até o fluxo híbrido.

**Não é um espelho da versão atual do repositório privado** `kfeernandesk/Loopingbr_publisher`: ali foram adicionados posteriormente publicação avançada, Shorts, agendamento, diagnósticos e controle de republicação. O aplicativo híbrido presente em `apps/publisher-hibrido` contém seu próprio executor e workflow operacional.

Os scripts desta pasta são incluídos para estudo e comparação arquitetural, sem publicar por conta própria. Para novos testes, prefira o aplicativo híbrido e siga o guia de configuração do projeto principal.
