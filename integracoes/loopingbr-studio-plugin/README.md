# LoopingBR Studio Público 1.8.0 — Cópia de distribuição

Esta é uma cópia INDEPENDENTE, preparada a partir do fluxo do LoopingBR Studio privado v1.7.2. Não muda nem instala nada no plugin original.

Use `@LoopingBR Studio Público` após instalar esta cópia na conta elegível. Inicie com “Começar” ou descreva seu vídeo. A geração depende de ferramentas e limites disponíveis à conta ChatGPT do usuário. Não há integração automática com Google Drive ou Publisher; exporte sua thumbnail e importe manualmente no LoopingBR Desktop.

## Resumo
- 3 conceitos Curiosidade, Emoção e Cinema, depois A/B/C e extras opcionais.
- Envio opcional de foto do rosto e foto do ambiente (sem armazenamento persistente pelo plugin).
- Aprovação antes de gerar e escolha de 3 horizontais OU 3 verticais.
- Uma thumbnail por chamada, sem mosaicos.
- Não há API de imagem externa, cobrança própria, serviço hospedado ou banco de dados incluídos no pacote.

## Distribuição
A criação local desta cópia NÃO a torna pública. A publicação para usuários aleatórios exige envio pelo portal oficial de plugins, revisão e publicação aprovada. Veja GUIA-DISTRIBUICAO.md entregue fora deste ZIP.
