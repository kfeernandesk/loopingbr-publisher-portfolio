# Proveniência e organização da edição de portfólio

- Aplicativo híbrido: extraído da distribuição **LoopingBR Publisher Híbrido v1.0.14.1 LAB**, em 16/11/2026, mantendo os arquivos Go, recursos, testes e scripts de build/inicialização.
- Plugin Studio: fonte da distribuição **LoopingBR Studio Público v1.8.0**.
- Publicador clássico: fonte da exportação anterior **LoopingBR Publisher Cópia Limpa Para Amigo**, para referência histórica.
- Repositório operacional original: `kfeernandesk/Loopingbr_publisher`, branch `main`, analisado na revisão; o estado exato do código desse repositório não está sincronizado integralmente nesta edição de portfólio.

## Critérios de limpeza

- Arquivos de código, testes e recursos embarcados permanecem sem alterações de lógica.
- Executáveis compilados não entram no ZIP de código; são fornecidos em pacote Windows independente.
- Foram removidos do repositório de portfólio os documentos históricos de testes e mudanças de versões anteriores, para evitar repetição de informações obsoletas.
- Não foram importados pedidos JSON reais, tokens, dados privados ou logs de usuário.
- A documentação de instalação, arquitetura, segurança e testes foi reescrita para um leitor técnico que não participou do desenvolvimento.

Esta organização é uma cópia para apresentação técnica, sem afetar o sistema original.
